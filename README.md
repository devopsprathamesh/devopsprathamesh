## 📌 Featured Project

### [kubernetes-homelabsetup](https://github.com/devopsprathamesh/kubernetes-homelabsetup)

A fully automated Kubernetes homelab — `git clone` → `make up` → a real 4-node
kubeadm cluster (1 control plane + 3 workers) on Vagrant + VirtualBox, with Cilium
as the CNI and Ansible bootstrapping everything entirely inside the VMs. Every
node's CPU/RAM/disk is configurable through a single `config.yaml` to fit whatever
machine you're running it on — live-tested end to end, including a genuine
from-scratch `git clone` run, with every real failure hit along the way documented
with root cause and fix.

🎥 Full walkthrough on [SquareKubeLab](https://www.youtube.com/@SquareKubeLab) — coming soon.
